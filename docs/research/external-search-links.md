# Taiwan e-commerce external search links


> Research snapshot from 2026-10-28; these findings are not product rules. Current rules live in [docs/product-spec.md](../product-spec.md).

**Scope and method.** Checked 2026-10-28. Each search URL below was fetched once with `鳳梨酥`; HTTP status and redirects are recorded. Terms, robots, and affiliate evidence are from the cited platform-owned pages. This concerns a human clicking an ordinary external hyperlink only; TaiwanHaul does not fetch or show platform pages. `UNKNOWN` means the cited official material or this single fetch did not establish the fact. This is research, not legal advice.

## Shopee Taiwan (shopee.tw)

- **Search / login — OBSERVED.** One fetch of [`https://shopee.tw/search?keyword=%E9%B3%B3%E6%A2%A8%E9%85%A5`](https://shopee.tw/search?keyword=%E9%B3%B3%E6%A2%A8%E9%85%A5) returned HTTP **200**, with no redirect. No login challenge was observed in that HTTP response; whether all users can see rendered results without login is **UNKNOWN** from a status-only fetch.
- **Linking / framing / marks — OBSERVED.** Shopee Terms §3.2 state: “我們歡迎您從您的網站連結至本網站，但前提是您的網站並未暗示獲得Shopee的任何背書或與其有任何關聯” (“We welcome links from your website, provided it does not imply Shopee endorsement or affiliation”). §3.1 says: “如未事先獲得我們的書面同意…不得用鏡像或框架方式…展示” (“without prior written consent, do not mirror or frame any part/all of the site”). It further says marks are Shopee/third-party property and no right/license to use them is granted. Source: [Shopee Terms of Service](https://help.shopee.tw/portal/4/article/77267).
- **Robots — OBSERVED, crawler-only.** [Shopee robots.txt](https://shopee.tw/robots.txt) has specific disallows for some search query patterns (e.g. `Disallow: /search*hashtag=` and `/search?shop=`) but no blanket search disallow under `User-Agent: *`; the tested keyword URL is not among those listed. **Robots rules govern automated crawlers, not a human clicking an external link, and do not by themselves ban linking.**
- **Affiliate / eligibility — OBSERVED.** The [Shopee Affiliate agreement](https://help.shopee.tw/portal/4/article/77310-%E8%9D%A6%E7%9A%AE%E8%81%AF%E7%9B%9F%E8%A8%88%E7%95%AB%E7%B4%84%E5%AE%9A%E6%A2%9D%E6%AC%BE) §2.3(c) says: “僅現持中華民國身分證者申請參與蝦皮分潤計畫，其餘身分則不具備…” (“Only current holders of an ROC national ID may apply; other identities are ineligible”). §2.2 grants use of Shopee-provided affiliate links only for the program and provides no general IP license. So a TaiwanHaul operator without an ROC ID cannot qualify; that does not prohibit ordinary non-affiliate links.
- **Verdict — LIKELY OK.** The Terms expressly welcome ordinary links with a no-endorsement condition; do not frame the page or use Shopee branding without permission.
